Situations got updated to version 4.5. The update includes at least:
* Updated application framework
* Added support for startup actions - on any app startup or once after a boot
* Added support for device orientation condition
* Increased maximum plugin instance counts

In addition, Sailfish is be getting:
* Added support for NFC toggle and tags
* Added support for privacy switch
* Fixed some non-root actions
* Fixed Bluetooth plugins with app support

Some further updates are also already in pipeline, including a Duration condition and a separate "Restore" setting for actions - which can be used to make any situation actions act more like one time triggers instead of remembering the state and returning to it at situation end.
